# Arabic Learning Suite | تعلم العربية

منصة متكاملة لتعلم اللغة العربية مع تحليلات متقدمة لتتبع التقدم.

## المميزات

- **الحروف العربية** — تعلم الـ٢٨ حرفًا مع أمثلة تفاعلية
- **المفردات** — بطاقات تعليمية بالكلمات مصنفة حسب المستوى
- **الاختبارات** — اختبارات متعددة الخيارات لقياس المعرفة
- **التحليلات** — رسوم بيانية لتتبع التقدم الأسبوعي والشهري

## تشغيل المشروع

```bash
npm install
npm run dev
```

## النشر على Vercel

```bash
vercel deploy
```

## التقنيات المستخدمة

- Next.js 14
- TypeScript
- Tailwind CSS
- Recharts
